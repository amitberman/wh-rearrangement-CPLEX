# wh_30x30-9-10-5-0

This directory contains a larger and harder `30x30` benchmark set.

Characteristics:

- `30x30` map
- `9` agents
- `10` obstacle entries per scenario
- `5` active rearrangement tasks per scenario
- a central shelf block with wide outer lanes, longer task routes, and more background agent traffic

Files:

- `wh_30x30.map`: shared map
- `wh_30x30-9-10-5-0.scen` to `wh_30x30-9-10-5-0-10.scen`: 11 scenario instances

The format is documented in [`SCENARIO_FORMAT.md`](/home/nir.miller/wh-rearrangement-CPLEX-main/SCENARIO_FORMAT.md).
