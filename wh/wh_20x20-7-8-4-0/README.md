# wh_20x20-7-8-4-0

This directory contains a harder `20x20` benchmark set with more agents.

Characteristics:

- `20x20` map
- `7` agents
- `8` obstacle entries per scenario
- `4` active rearrangement tasks per scenario
- a central shelf block with longer active tasks and extra agent traffic through shared corridors

Files:

- `wh_20x20.map`: shared map
- `wh_20x20-7-8-4-0.scen` to `wh_20x20-7-8-4-10.scen`: 11 scenario instances

The format is documented in [`SCENARIO_FORMAT.md`](/home/nir.miller/wh-rearrangement-CPLEX-main/SCENARIO_FORMAT.md).
